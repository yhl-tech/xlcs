# Vue 3 迁移文档目录

本目录包含原生 JavaScript 项目迁移到 Vue 3 的完整文档。

## 文档结构

### 1. [Vue 3 迁移总览](./vue3迁移-总览.md) 📋
**适合**: 项目经理、架构师、所有团队成员

**内容**:
- 项目概况和迁移目标
- Vue 3 项目结构设计
- 核心迁移策略（状态管理、组件拆分、Composables）
- 分阶段实施计划（6 个阶段）
- 关键原始文件映射表
- 依赖配置
- 预估工作量和风险评估

**阅读时间**: 10-15 分钟

---

### 2. [appMain.js 迁移详解](./vue3迁移-appMain详解.md) 🔍
**适合**: 负责核心业务逻辑迁移的开发者

**内容**:
- 15 个功能模块的详细划分
- 每个模块的代码位置、核心函数、迁移目标
- 迁移优先级（4 批次）
- 风险评估（高/中/低）
- 迁移检查清单

**阅读时间**: 15-20 分钟

---

### 3. [高难度模块迁移指南](./vue3迁移-高难度模块.md) 💡
**适合**: 负责复杂模块迁移的高级开发者

**内容**:

- WebSocket/TTS 系统
- 会话快照恢复系统
- 预览窗口系统

**每个模块包含**:
- 难点分析
- 完整的迁移策略代码
- 注意事项和陷阱

**阅读时间**: 30-40 分钟

---

### 4. [快速参考](./vue3迁移-快速参考.md) ⚡
